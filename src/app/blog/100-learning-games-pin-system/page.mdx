## 1. 3자리 PIN 번호 시스템이란?

각 배움게임(팩 1~10, 총 100종)에는 고유한 3자리 식별 번호가 부여되어 있습니다.

- 예: **001번** (분수 크기 비교 배틀)
- 예: **045번** (초등 필수 영단어 러너)
- 예: **082번** (역사 인물 타임머신 퀴즈)

선생님이 칠판에 `"오늘은 045번 게임으로 단어 복습하자!"`라고 적어주기만 하면, 학생들은 태블릿 화면 상단의 키패드에서 `0`, `4`, `5` 세 개 숫자만 터치하면 즉시 해당 학습 게임으로 워프합니다.

## 3. 웹 성능 최적화: 25대 동시 접속에도 버티는 비결

학교 Wi-Fi 환경은 생각보다 열악합니다. 25명의 학생이 동시에 웹페이지를 요청할 때 외부 서버 트래픽이 몰리면 로딩 지연이 발생합니다.

이를 해결하기 위해:
1. **단일 HTML/JS 번들링**: 불필요한 대용량 라이브러리를 걷어내고 순수 HTML5 Canvas와 경량 모듈로 압축
2. **Next.js 정적 에셋(SSG) 서빙**: 서버 부하 없는 클라이언트 사이드 실행
3. **오프라인 캐싱 지원**: 한 번 접속한 게임은 인터넷이 불안정해도 브라우저 캐시로 즉각 구동

교육 현장에서 기술의 위대함은 복잡한 기능이 아니라, **수업의 흐름을 1초도 방해하지 않는 매끄러움**에서 나온다는 것을 배웠습니다.
