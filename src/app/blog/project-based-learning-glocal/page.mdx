## 1. 프로젝트 설계: 개념기반 탐구학습(CBI) 프레임워크

단순한 지식 암기가 아니라, 상위 개념(지속가능성, 공존, 시스템)으로 사고를 확장하도록 단원을 재구성했습니다.

- **핵심 질문**: *"바다와 인간은 어떻게 서로의 미래를 지켜줄 수 있을까?"*
- **1단계: 현장 필드워크**: 여수 웅천 해변과 신덕 해변 플로깅(쓰레기 줍기) 및 미세플라스틱 분포 조사
- **2단계: 데이터 시각화**: 태블릿 스프레드시트에 수거한 쓰레기 종류(어구, 스티로폼 부표, 일회용 컵)를 기록하고 인터랙티브 차트 생성
- **3단계: 공공 캠페인 웹페이지 제작**: 아이들이 직접 HTML/CSS 코딩과 노코드 툴을 활용해 시민들에게 바다 쓰레기 분리배출을 촉구하는 웹사이트 제작
