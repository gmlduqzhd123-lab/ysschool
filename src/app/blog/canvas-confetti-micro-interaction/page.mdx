## 1. 왜 DOM 요소가 아니라 Canvas 기반인가?

수백 개의 색종이 조각을 `<div>` 태그로 띄우고 CSS 애니메이션을 먹이면, 저사양 안드로이드 태블릿 25대가 돌아가는 교실에서는 브라우저 렌더 트리가 폭발하며 심각한 프레임 드랍(Jank)이 발생합니다.

반면 `canvas-confetti`는 단 하나의 `<canvas>` 컨텍스트 위에서 수천 개의 파티클 물리 연산을 GPU 가속으로 처리하기 때문에, 구형 기기에서도 부드러운 60FPS를 보장합니다.

```ts
import confetti from 'canvas-confetti';

export function fireSchoolSuccessConfetti() {
  const count = 200;
  const defaults = {
    origin: { y: 0.7 },
    spread: 360,
    ticks: 100,
    gravity: 1.2,
    decay: 0.94,
    startVelocity: 30,
  };

  confetti({
    ...defaults,
    particleCount: Math.floor(count * 0.25),
    colors: ['#38bdf8', '#818cf8', '#f59e0b', '#10b981'],
  });
}
```
