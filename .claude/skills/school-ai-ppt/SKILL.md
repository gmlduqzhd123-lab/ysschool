# 학교 AI 사업 운영 사례 발표 PPT

여수한려초 「AI 이음」 발표 자료(42쪽)를 만든 과정을 재사용 가능한 절차로 정리한 스킬이다.
실제 생성 코드는 `examples/hanryeo_build.js`에 있다. 새 학교·새 발표도 이 파일을 복사해 내용만 바꾸는 방식으로 만든다.

**먼저 `anthropic-skills:pptx` 스킬을 로드한다.** pptxgenjs 주의사항, validate.py, soffice.py 경로가 거기 있다.

## 1. 입력 정리

1. **초안 PPT**: `markitdown draft.pptx`로 본문과 발표자 메모를 모두 읽는다. 메모에 더 자세한 원문이 있는 경우가 많다.
2. **필수 내용 목록**: 사용자가 준 번호 목록을 체크리스트로 만들고, 각 항목이 몇 쪽에 들어가는지 마지막에 표로 보고한다.
3. **사용자가 고친 수정본 PPT**가 오면: 내 결과물과 `markitdown` 텍스트를 `diff <(sort -u mine.md) <(sort -u rev.md)`로 비교해 바뀐 문구만 생성 스크립트에 반영한다(줄바꿈 위치까지).
4. **사진**
   - 채팅에 붙인 이미지는 앞의 일부만 파일로 저장될 수 있다. 저장된 파일 목록을 확인하고, 못 받은 사진은 **zip으로 다시 올려 달라고** 요청한다.
   - zip은 `python3 -I scripts/unzip_photos.py photos.zip OUT_DIR`로 푼다(한글 cp949 파일명 처리, p0~pN으로 저장, 원래 이름 출력). 압축 파일은 빈 새 폴더에 푼다.
   - 각 사진을 직접 열어 보고 어떤 슬라이드에 맞는지 판단한다.
5. **QR 코드는 연결 대상을 추측하지 않는다.** 모르면 묻고, 추측해 넣었다면 반드시 "추측"이라고 알린다.

## 2. 구성(검증된 흐름)

표지 → 목차 → 6개 섹션(각 섹션 앞에 남색 구분 슬라이드) → 성찰·과제 → 감사 인사.

| 섹션 | 내용 |
|---|---|
| 01 걸어온 길 | 연도별 타임라인, 연도별 사업 1장씩, 인프라 사진 |
| 02 비전 | 학교의 브랜드 모델(예: I·E·U·M 네 축) |
| 03 선도학교 | 핵심(코스웨어·에듀테크) → 수업 사진 → 수업 적용 흐름 → 플랫폼 화면 → 학생 주도성 |
| 04 중점학교 | 핵심(교육과정 재구성×바이브 코딩) → 학년별 → 시수 차트 → 학년 사례 → 바이브 코딩 과정 → 동아리 → 동아리 사진 → 학생 산출물 → 패들렛(QR) |
| 05 연계 시너지 | 도구 전체 보기 → 예산 연계 흐름 → 교사 공동 설계 → 교사 제작 도구 → 웹앱 모음(QR) → 교과 적용 사례 ①② → 플랫폼 배포 → 코디네이터 |
| 06 성과와 확산 | 1학기 발표회 → 발표회 사진 → 2학기 계획 → 기록 수치·다음 과제 |

- 한 슬라이드에 메시지 하나. 각 내용 슬라이드 하단에 남색 알약 모양 "한 줄 메시지(takeaway)"를 둔다.
- 분량을 늘려도 되면 사진은 별도 사진 슬라이드로 넣는다(왼쪽 사진 + 오른쪽 아이콘 3~4줄 설명).
- 만화형 설명 이미지가 5장이면 2장의 슬라이드로 나눈다(3+2). 한 장에 5개는 너무 작다.
- 사용자 자료에 없는 내용(학년별 세부 주제, 행사 진행 방식 등)을 채웠다면 해당 쪽 번호를 마지막에 **"예시 문구, 실제 내용으로 교체 필요"**로 반드시 알린다.

## 3. 디자인 시스템 (examples/hanryeo_build.js)

- 16:9 와이드(`LAYOUT_WIDE`, 13.33×7.5in), 글꼴 맑은 고딕.
- 색: 남색 `0E1A3A`(주), 골드 `C8A15A`(강조), 청록 `1FA39A`(보조), 배경 `F7F8FC`, 카드 흰색+옅은 그림자.
- 모티프: 원형 배지 안의 react-icons(lucide) 아이콘. 구분·표지 슬라이드는 남색 배경 + 큰 원 장식.
- 주요 헬퍼
  - `content(tag, title, notes)`: 상단 청록 태그 + 30pt 제목 + 발표자 메모
  - `divider(no, title, sub, icon)`: 섹션 구분 슬라이드
  - `iconCards(s, [[icon, head, bullets, num]])`: 2~5열 카드
  - `photoSlide(tag, title, notes, files, points|null, takeaway, qr?)`: 사진(비율 유지, 흰 액자) + 오른쪽 설명 또는 QR 카드 `[file, 제목, 설명]`
  - `takeaway(s, text)`: 하단 한 줄 메시지
  - `pic(s, file, x, y, w, h)`: 비율 유지 배치, 1800px로 줄이고 JPEG로 압축(용량 관리)
- 아이콘 이름은 `react-icons/lu`에 실제 있는지 먼저 확인한다(없으면 렌더 단계에서 오류).

## 4. 빌드와 검수

```bash
npm install pptxgenjs react-icons react react-dom sharp   # require가 실패할 때만
IMG_DIR=./images/ PHOTO_DIR=./photos/ OUT=deck.pptx node build.js
python $PPTX_SKILL/scripts/office/validate.py deck.pptx
PPTX_SKILL=... sh scripts/render_grid.sh deck.pptx qa/    # 21장씩 묶은 확인용 그리드
```

- 그리드 이미지를 직접 보고 글자 넘침, 겹침, 사진 비율, 쪽마다 같은 제목 위치인지 확인한 뒤 고친다.
- 슬라이드 순서를 바꿀 때는 스크립트 본문을 `// ` 주석이나 `await` 줄 단위 블록으로 나눠 재배열한다.
- 버전마다 파일명을 `_v2`, `_v3` … `_final`로 올려 이전 결과를 보존한다.

## 5. 결과 보고

- 파일을 사용자에게 보내고, 짧게 정리한다.
  - 필수 내용 → 쪽 번호 대응표
  - 사진/QR이 들어간 쪽
  - 확인이 필요한 점(추측한 QR 짝, 예시 문구가 남은 쪽, 못 받은 사진, 파일 용량)
